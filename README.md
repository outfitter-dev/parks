# Parks

Outfitter's design system: **P**atterns · **A**ssets · **R**ules · **K**its · **S**tyles.

Parks will ship as one package, `@outfitter/parks`, with tokens, theme CSS, components and the UI rules, plus a shadcn registry and a showcase at `parks.outfitter.dev`.

This repository is being set up. The code is moving here from `outfitter-dev/outpost` (`packages/parks` and the workbench), with its history. Nothing is published yet.
